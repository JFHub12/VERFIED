A full-stack, dual-runtime e-commerce web platform engineered for luxury lifestyle goods (clothing, home fragrance, curated accessories, and certified electronics). The system pairs a high-performance **React 19** single-page architecture with an **Express API Gateway** reverse-proxying into an asynchronous **Python 3 / SQLite** transactional microservice.
